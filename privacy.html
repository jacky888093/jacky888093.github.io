Privacy Policy

How the local application and this public website handle information.

Google authorization and YouTube

The local application uses Google OAuth to authorize its use of YouTube API Services. It requests these scopes:

youtube.readonly
Verify the authorized YouTube channel and check the status of a submitted video, including its privacy and schedule settings.
youtube.upload
Send a selected video and its publishing details to YouTube when uploading is enabled and you explicitly approve the submission.

The app uses OAuth credentials to authenticate requests to Google. During an authorized submission, YouTube receives the selected video and publishing details such as its title, description, audience setting, and scheduled release time. See the Google Privacy Policy.

Local storage and optional tools

OAuth credentials are stored in local files. Video paths, metadata, drafts, series, and publishing history are stored in a local SQLite database and related local files. Database backups, optional drafting task files, and extracted frames stay on the computer unless you move or share them.

If you choose to share a drafting task with Codex, that service handles the information and frames you share. The local app does not send drafting tasks to Codex automatically.

The developer does not sell user data.

Revoke access and manage local data

Open Google Account third-party connections, select the app, and remove its access. Revocation does not remove local records, backups, or videos already on YouTube. You can delete individual library records in the app and manage local backup files on your computer. Deleting a library record leaves the source video in place.

This public website

These pages have no analytics, tracking scripts, or sign-in forms. GitHub Pages hosts the site and logs visitor IP addresses for security purposes. See the GitHub General Privacy Statement.

Contact the developer

For privacy questions or data requests, contact the developer through the GitHub profile or open an issue in the public website repository if Issues is enabled. Issues are public. Keep credentials, private video information, and personal data out of issue posts.
